# Intro

These docs aim to provide a guide to the API of the online game, Payphone Tag.

:::warning[Disclaimer]
These docs are not official, this is a community project. Some things may be incorrect.
:::

:::danger
All API requests are subject to change as Payphone Tag updates in the future. Do not expect API's to stay the same, although these docs will try to be updated when possible. Please note this if making use of this API, Here be dragons.
:::

:::info
These docs are not complete, expect some API endpoints to be missing!
:::

All API requests will be made through:
```
https://payphonetag.com/api/
```
