### Payload
```
{pin: agent pin - string}
```
### Response
```
{
"color": Hex code - string,   
"emoji": Emoji of user - string, 
"hasRecoveryCode": boolean, 
"id": public ID of user - number,    
"mfaEnabled": boolean,    
"name": agent name - string,    
"shape": shape of agent - string
}
```

### Response Format
JSON
